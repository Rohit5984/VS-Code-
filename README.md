🚀 Universal Software Installer

Create a folder and name it anything you like.

Put all your .exe and .msi software inside the folder.

Put install.ps1 in the same folder.

Right-click install.ps1 and select Run with PowerShell.

The script will automatically install all the software inside the folder.

It also creates an install.log file with the installation results.

⚡ That's It!

Put software → Run script → Everything installs automatically. 🚀
